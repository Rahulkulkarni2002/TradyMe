      How do I connect Alpaca?
      1. Log in at app.alpaca.markets and switch to your Paper account (top-left).
      2. Find API Keys → Generate New Keys. Copy the Key and the Secret (the secret is shown only once).
      3. In the TradyMe folder, copy .env.example to a new file named .env and paste the two keys after ALPACA_API_KEY= and ALPACA_SECRET_KEY=. Keep ALPACA_PAPER=true.
      4. Restart TradyMe (Ctrl+C, then python run.py). This box turns green.

      🔒 Never share your keys with anyone (not even in chat). The .env file never goes to GitHub.
